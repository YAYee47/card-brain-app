# Card Brain 環境建置手冊

本手冊將引導您如何在本地端從零開始架設 Card Brain (多軌極速記帳) 專案。

## 系統需求
- **作業系統**：Windows / macOS / Linux
- **Python**：v3.10 或以上版本
- **Node.js**：v18 或以上版本 (推薦使用 nvm 管理)
- **npm** 或 **yarn**：Node.js 內建套件管理工具

---

## 🔧 1. 後端 (API Server) 建置

後端使用 Python 的 FastAPI 框架建置，搭配 SQLite 資料庫與 Google Gemini AI。

### 步驟 1：建立虛擬環境
請開啟終端機 (Terminal / PowerShell)，進入 `backend` 目錄，並建立一個獨立的 Python 虛擬環境：
```powershell
cd backend
python -m venv venv
```

### 步驟 2：啟動虛擬環境
- **Windows**:
  ```powershell
  .\venv\Scripts\activate
  ```
- **macOS / Linux**:
  ```bash
  source venv/bin/activate
  ```

### 步驟 3：安裝依賴套件
```powershell
pip install -r requirements.txt
```

### 步驟 4：設定環境變數
在 `backend` 目錄下建立一個 `.env` 檔案，並填入以下內容：
```ini
# Google Gemini API Key (用於 AI 收據辨識)
GEMINI_API_KEY=your_gemini_api_key_here
```

### 步驟 5：初始化資料庫與啟動伺服器
請確認您的終端機已套用虛擬環境，並輸入以下指令啟動：
```powershell
# 將當前目錄加入 PYTHONPATH (Windows)
$env:PYTHONPATH="."
# 啟動 Uvicorn 伺服器
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
後端成功啟動後，API 文件將可於 `http://localhost:8000/docs` 檢視。

## 📱 2. 前端 (Mobile App) 建置

前端使用 React Native 搭配 Expo 框架開發，讓您可以同時在 iOS 與 Android 上測試。

### 步驟 1：安裝依賴套件
開啟一個**新的**終端機視窗，進入 `mobile` 目錄，並安裝所有 npm 套件：
```powershell
cd mobile
npm install
```

### 步驟 2：設定環境變數
在 `mobile` 目錄下建立一個 `.env` 檔案，告訴 App 後端伺服器的 IP 位置：
```ini
# 請將 IP 替換為您電腦在區網內的真實 IP，不要填 localhost
EXPO_PUBLIC_API_URL=http://192.168.x.x:8000/api/v1
```

### 步驟 3：啟動 Expo 開發伺服器
若您使用實體手機透過區域網路連線，建議在啟動時強制綁定區網 IP：
```powershell
# 替換為您的區網 IP
$env:REACT_NATIVE_PACKAGER_HOSTNAME="192.168.x.x" 
npx expo start -c
```

### 步驟 4：在手機上運行
1. 在您的實體手機上下載 **Expo Go** App (iOS / Android)。
2. 將手機連上與電腦**相同**的 Wi-Fi 網路。
3. 使用相機或 Expo Go App 掃描終端機上出現的 QR Code 即可載入開發版 App。

---

> [!TIP]
> **常見問題排解**
> 1. **手機畫面上顯示 Network Error**：請檢查 `mobile/.env` 中的 IP 是否正確，以及手機與電腦是否在同一個 Wi-Fi 下。此外，請確認電腦防火牆有允許 Port 8000 的連入。
> 2. **AI 收據辨識一直報錯**：請確認 `backend/.env` 檔案存在，且 `GEMINI_API_KEY` 是有效的。

## 🚀 3. iOS 實機離線版 (Release) 打包指南

如果您希望將 App 真正安裝到 iPhone 桌面，並在沒有 Wi-Fi 或傳輸線連線電腦的情況下獨立運作（例如帶出門記帳），請執行 Release 打包：

### 步驟 1：確認 Xcode 開發工具綁定
若為首次在 Mac 上執行原生打包，請先於終端機執行此指令以正確綁定 Xcode：
```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

### 步驟 2：設定 Xcode 憑證 (Apple 免費開發者必做)
1. 點兩下開啟 `mobile/ios/cardbrainmobile.xcworkspace` (會開啟 Xcode)。
2. 點選左側專案名稱 `cardbrainmobile`，接著點擊中間 `Targets` -> `cardbrainmobile` -> 上方的 **Signing & Capabilities** 標籤。
3. 勾選 **「Automatically manage signing」**。
4. **Team** 下拉選單中選擇您的名字 (Personal Team)。
5. 維持 Xcode 開啟狀態，進入下一步。

### 步驟 3：插線並透過 Xcode 執行打包 (穩定度最高)
因部分終端機環境執行 `npm` 打包指令時，容易遇到無法正確判定實體設備或強制開啟模擬器的 Bug，因此強烈推薦直接使用 Xcode 原生介面進行離線打包：

1. **選擇實體手機**：將 iPhone 插上 Mac（解鎖螢幕並信任電腦）。在 Xcode 畫面上方正中央的設備清單中，選中您的「實體 iPhone」（切勿選擇 Simulator）。
2. **切換為 Release 模式**：
   - 點擊 Mac 最上方選單列：**Product** -> **Scheme** -> **Edit Scheme...**。
   - 在彈出視窗的左側點選 **Run**，右側找到 **Build Configuration**，將其從 `Debug` 下拉改為 **`Release`**，然後關閉該視窗。
3. **開始打包**：點擊 Xcode 左上角的 **`▶ (Play 鍵)`**，或按快捷鍵 `Cmd + R` 開始編譯。

等待 5~15 分鐘（看到 Xcode 顯示 `Build Succeeded` 為準），App 會自動灌入手機並開啟。此時即可放心地拔掉傳輸線、關閉電腦 Wi-Fi 享受完全獨立的離線記帳！

> [!WARNING]
> **免費用戶的 7 天限制**
> 使用免費 Apple ID 憑證（Personal Team）安裝的原生 App 壽命僅有 7 天。7 天一到 App 將會閃退無法開啟，您必須重新將手機插回 Mac，並再次執行打包指令來為 App 續命 7 天。日常頻繁修改程式碼時，建議維持使用 Debug 模式（Expo Go 或 `--dev-client`）；僅在需帶出門實測時才打包 Release 版。
