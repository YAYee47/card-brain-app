# Card Brain 程式碼架構導覽

這是一份給您的「地圖」，幫助您快速了解專案中每一個檔案與資料夾負責的工作。專案主要分為 **後端 (backend)** 與 **前端 (mobile)** 兩大區塊。

---

## 💻 後端 (Backend) - FastAPI + Python

後端是整個系統的大腦，負責所有複雜的運算、資料庫存取與 AI 串接。

### 📌 核心設定 (`backend/app/`)
- **`main.py`**：後端程式的**總入口點**。負責啟動 FastAPI 伺服器、設定跨域請求 (CORS)、註冊生命週期 (Lifespan, 初始化 DB 與啟動 APScheduler)，並將所有 API 路由註冊進來。
- **`db/database.py`**：資料庫連線引擎設定。預設連線至 Neon.tech 雲端 Serverless PostgreSQL (`asyncpg`)，亦相容本地 SQLite 模式。
- **`db/seed.py`**：初始資料庫種子腳本。寫入 5 家銀行信用卡、初始權益規則與預設個人化結帳日。

### 📌 API 進入點 (`backend/app/api/v1/endpoints/`)
這些檔案定義了前端可以呼叫的網址 (URL) 路徑：
- **`transactions.py`**：處理「記帳」相關請求。包含呼叫 AI 視覺解析收據、玉山 Unicard 方案整月追溯重算邏輯，以及存入記帳資料庫的路由。
- **`recommend.py`**：處理「權益推薦」請求。接收前端傳來的消費通路與金額，支援 `exclude_registration` 過濾需登錄項目，回傳最優卡片列表。
- **`dashboard.py`**：處理「儀表板」請求。負責將首頁需要的各張卡片進度條、當期總花費、累積回饋等資訊打包傳給前端。
- **`cards.py`**：處理「卡片管理」請求。列出系統擁有的所有卡片，以及使用者勾選「已擁有」卡片與自訂結帳日的邏輯。
- **`users.py`**：處理「使用者登入與註冊」請求。實作基於 UUID 的設備綁定與原生 `bcrypt` 的密碼安全雜湊 (Password Hash) 防護機制。
- **`alerts.py`**：處理「通知警報」請求。提供使用者查詢 80% 預警、100% 封頂與權益異動清單，並支援標記已讀。

### 📌 核心服務邏輯 (`backend/app/services/`)
這裡是系統真正運作「商業邏輯」的地方：
- **`transaction_service.py`**：**【回饋精算引擎】** 負責比對通路、換算台幣、計算基礎與加碼回饋金，並在應用層執行動態 UPSERT 累計 `MonthlyUsage`。
- **`recommend.py`**：**【推薦核心】** 負責執行複雜的比對邏輯。結合「台灣常見場景智慧字典」與「特店分詞模糊比對」，計算每張卡的 Base/Bonus 趴數是否達上限，最後排出最優推薦。
- **`ocr.py`**：**【AI 辨識】** 負責與 Google Gemini 3.5 Flash 溝通（使用官方 `google-genai` SDK）。接收圖片，下 Prompt 萃取出消費金額、幣別 (TWD/JPY/KRW/CNY/USD)、日期與商家名稱。
- **`exchange_rate.py`**：**【即時匯率】** 串接 ExchangeRate-API 開放免金鑰端點，抓取即時外幣匯率，並內建離線備援匯率。
- **`billing_cycle.py`**：**【帳單週期】** 根據每張卡片的自訂結帳日 (1~31 號) 與消費時間，動態精準計算當前帳單週期的起始日與結束日。
- **`scheduler.py`**：**【排程器】** APScheduler 定時器。設定每季 (1, 4, 7, 10 月) 1 日 00:05 喚醒爬蟲，以及每日 09:00 執行全額度水位掃描產生警報。

### 📌 資料結構定義
- **`models/*.py`**：SQLAlchemy **8 大 ORM 資料庫模型**（User, Card, CardBenefit, UserCard, Transaction, MonthlyUsage, AppAlert, BenefitSnapshot）。
- **`schemas/*.py`**：Pydantic v2 **資料格式驗證 (Type)**。負責檢查前後端傳遞之 JSON Schema 結構。

## 📱 前端 (Mobile) - React Native + Expo (SDK 57)

前端是使用者的操作介面，負責呈現漂亮的粉色質感畫面並將操作轉化為 API 請求送給後端。

### 📌 畫面佈局 (`mobile/app/(tabs)/`)
這裡的每個 `.tsx` 檔案都對應到底下導覽列的一個分頁 (Tab)：
- **`index.tsx` (額度儀表板)**：負責顯示「本期總消費」、「已賺回饋」與各張卡片的「動態回饋進度條」（<80% 綠色、>=80% 橘色警報、100% 紅色封頂）。
- **`recommend.tsx` (決策推薦)**：獨立的消費試算頁面。當您走進店家前，輸入店家或通道名稱查「刷哪張卡最賺」的介面。
- **`scan.tsx` (記帳分析)**：包含呼叫手機相機/相簿的 AI 視覺記帳、手動補登表單，支援外幣切換與原生小日曆。
- **`cards.tsx` (名下卡片)**：讓您打勾選擇自己錢包裡目前有哪些信用卡，並可個別修改結帳日。
- **`tutorial.tsx` (使用教學)**：App 的靜態使用秘笈與提示教學分頁。

### 📌 共用元件 (`mobile/components/scan/`)
- **`CurrencyPickerModal.tsx`**：底部半透明彈出幣別選單，支援 TWD, JPY, KRW, CNY, USD。
- **`DatePickerModal.tsx`**：封裝 `@react-native-community/datetimepicker`，鎖定 `themeVariant="light"`，防禦 iOS 日曆崩潰。

### 📌 API 串接 (`mobile/src/api/`)
- **`client.ts`**：Axios 網路設定，預設指向 Render 雲端後台 `https://card-brain-app.onrender.com/api/v1`，配置 45 秒超時容錯以應對 Render 冷啟動，並透過 Request Interceptor 自動附帶 `X-Device-UUID`。
- **`transactions.ts`**：負責將收據圖片送去後端 AI 辨識，以及送出最終記帳資料。
- **`recommend.ts`**：負責請求推薦卡片與最佳排序。
- **`cards.ts`**：負責請求卡片圖鑑與更新使用者持有狀態。
